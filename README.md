# Sistema de Producción de Fileteo

## Descripción
Sistema para registrar el proceso de fileteo de pescado, validar los pesos, calcular el rendimiento y clasificar los resultados.

## Requisitos
- Python 3 instalado.
- Git instalado para clonar el repositorio.

## Instalación

Clonar el repositorio:

    git clone https://github.com/GinaCalderon/sistema-produccion-fileteo.git

Entrar en la carpeta:

    cd sistema-produccion-fileteo

## Ejecución

Desde la carpeta principal, ejecutar:

    python python/Main.py

En Windows también puedes probar:

    py python/Main.py

## Funcionalidades
- Registro de producción.
- Validación de la masa total.
- Cálculo del porcentaje de rendimiento.
- Clasificación del rendimiento como bueno o malo.
